# My Watchlist

A learning project. Over eight weeks you will build a website that keeps a list of
movies and series you want to watch — you can add them, mark them as watched,
search them, and everything is saved so it is still there tomorrow. You start with
a page that does nothing, and you finish with a real application running on the
internet.

You do not need any programming background to start. The first task is installing
the tools.

## What you will have at the end

- **A working app on the internet**, at a link you can send to anyone.
- **A public code history** on GitHub showing eight weeks of work. This is a
  portfolio. Employers read these.
- **Real skills:** HTML, CSS, JavaScript, TypeScript, a web server, and a
  database. Not tutorial-following — code you wrote and can explain.

## Start here

1. Read [docs/SETUP.md](docs/SETUP.md) and do everything in it. It takes about two
   hours the first time. Do not skip steps.
2. Read [CONTRIBUTING.md](CONTRIBUTING.md). It explains how to save your work and
   how to send it to Ahmad for review.
3. Open [docs/CURRICULUM.md](docs/CURRICULUM.md) and start Task 1.1.

If you get stuck on any of this, that is expected. Ask.

## How to run the app

Open `app/index.html` in your browser. That is it — no build step, nothing to
install, until week 6.

The easier way, once VS Code is set up: right-click `app/index.html` and choose
"Open with Live Server". The page then reloads by itself every time you save,
which saves you thousands of clicks over eight weeks.
